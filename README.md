1. 先读 **参与反思** §〇 总览表，三十秒了解三次参与；
2. 按 §一 → §二 → §三 读原文转录，每节后附「当时的思考」与「后续结果」；

## 四、证据复现（纯文本命令回显）

所有证据均为命令回显或最小复现代码，任何人可独立复核：

**1. DNS 解析对比（参与 1 核心证据）**

```bash
nslookup github.com
nslookup github.com 8.8.8.8
```

判读：两条结果不一致，且前者不在 GitHub 常用网段（140.82.x / 20.205.x），即解析污染。污染应答具间歇性，若首次命中正常解析可多跑几次。整理日（11-22）复跑仍复现。

**2. 固定解析可达性与 git 连通性**

```bash
curl -sI --max-time 12 --resolve github.com:443:140.82.112.3 https://github.com
git ls-remote https://github.com/octocat/Hello-World.git HEAD
```

预期：前者返回 `HTTP/1.1 200 OK`；后者读回 `7fd1a60b... HEAD`（用公开示例仓库，不涉及个人仓库地址）。

**3. 命令级固定解析写法（参与 1 的解法）**

```bash
git -c http.curloptResolve=github.com:443:140.82.112.3 ls-remote <仓库URL>
git -c http.curloptResolve=github.com:443:140.82.112.3 push <远端名> <分支名>
```

`-c` 仅对本次命令生效，不改全局配置与 hosts。

**4. Overleaf 最小复现（参与 2）**

新建空 Overleaf 项目，贴入三行正文（见参与反思附录 C），编译即现 `! Undefined control sequence. l.3 \keywords`；在 `\begin{document}` 前加 `\newcommand{\keywords}[1]{\textbf{Keywords:} #1}` 后编译通过。任何 Overleaf 账号可复现。
